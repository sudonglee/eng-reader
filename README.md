# 결이 리더 (Read with Me) — 웹앱(PWA) v0.1

영어 그림책을 사진으로 찍으면 원어민 음성으로 읽어 주고, 다 읽은 뒤 퀴즈와 한글 해설로 이해도를 확인하는 iPad용 웹앱입니다. (`prd.md` 기준 MVP)

## 1. iPad에 설치하기

웹앱은 **HTTPS 주소**에 올려야 오프라인 사용·홈 화면 앱 설치가 됩니다. 가장 쉬운 방법은 GitHub Pages(무료)입니다.

### 방법 A. GitHub Pages (권장)
1. GitHub에서 새 저장소를 만듭니다 (예: `gyeol-reader`, Private도 가능하지만 Pages는 Public 저장소에서 무료).
2. 이 폴더의 파일 전체(`index.html`, `styles.css`, `sw.js`, `manifest.webmanifest`, `js/`, `icons/`)를 업로드합니다.
3. 저장소 **Settings › Pages › Branch: main / root** 저장 → 1~2분 뒤 `https://<아이디>.github.io/gyeol-reader/` 주소가 생깁니다.
4. iPad **Safari**로 그 주소를 열고 **공유 버튼 › 홈 화면에 추가**.
   - 홈 화면 앱으로 쓰면 Safari의 "7일 미사용 시 데이터 삭제" 규칙이 적용되지 않아 책과 기록이 안전하게 유지됩니다.

> 저장소가 Public이어도 책 사진·기록·API 키는 **iPad 안에만** 저장되고 GitHub에는 올라가지 않습니다. 올라가는 건 앱 코드뿐입니다.

### 방법 B. Mac에서 바로 띄워 보기 (테스트용)
```bash
cd gyeol-reader
python3 -m http.server 8000
```
iPad Safari에서 `http://<Mac의 IP>:8000` 접속. 오프라인·홈 화면 설치는 안 되고, 주소(IP)가 바뀌면 저장된 책이 보이지 않으니 **맛보기용**으로만 쓰세요.

## 2. 처음 설정
1. 책장 오른쪽 위 🔒 → 곱셈 문제로 부모 모드 진입
2. **⚙️ 설정 › Claude API 키** 입력 → "연결 확인" (키 발급: https://platform.claude.com)
3. **영어 음성**: iPad 설정 › 손쉬운 사용 › 읽기 및 말하기 › 음성 › 영어에서 *향상된/프리미엄* 음성(예: Ava, Zoe)을 내려받은 뒤 앱을 다시 열면 자동으로 가장 좋은 음성을 고릅니다. "미리 듣기"로 확인하세요.
4. 해설 말투(반말/존댓말), 퀴즈 난이도, 문제 수, 기본 속도, 자동 페이지 넘김 설정

## 3. 사용 방법
**부모 – 책 만들기**: 📚 책 관리 › 새 책 만들기 → 제목, 표지 → 📷 카메라로 한 쪽씩 찍기 (또는 앨범에서 여러 장) → 🔤 글자 추출 → 틀린 글자 수정 (한 줄 = 한 문장) → ✏️ 퀴즈 만들기 (미리 만들어 두면 아이가 기다리지 않음)

**아이 – 읽기**
| 동작 | 기능 |
|---|---|
| ▶ | 페이지 전체 읽기 (읽는 문장·단어 하이라이트) |
| 단어 탭 | 그 단어만 읽기 |
| 단어 길게 누르기 | 한글 뜻 + 문장 해석 (인터넷 필요) |
| 문장 앞 🔊 | 그 문장만 읽기 |
| ✂️ 구간 → 첫 단어, 끝 단어 탭 | 고른 구간만 읽기 (문장을 넘어가도 됨) |
| 🔁 | 1번 → 2번 → 3번 → 계속 반복 |
| 🐢 🙂 🐇 | 0.5x / 0.75x / 1.0x / 1.25x 속도 |
| 좌우로 밀기 | 페이지 넘기기 |

마지막 페이지에서 **퀴즈 풀기** → 문제·보기 영어 음성, "한글로 보기" 힌트 → 고르면 바로 채점 + 효과음 → 한글 해설(음성) + 근거 문장(탭하면 원어민 음성) → 결과 별점, 틀린 문제 다시 풀기

**부모 – 📊 학습 기록**: 최근 7일 읽은 날, 책별 읽은 횟수·최고 점수, 최근 퀴즈 답안, 자주 틀린 문제, 많이 눌러 본 단어

**💾 백업**: 설정 › 백업 파일 저장 (가끔 해 두세요. API 키는 포함되지 않음)

## 4. PRD와 다른 점 (웹앱이라서)
| PRD | 이 버전 | 이유 |
|---|---|---|
| Apple Vision 온디바이스 OCR | Claude Vision OCR (페이지당 API 1회) | 웹에서는 iPad OCR을 쓸 수 없음. 대신 그림책 글씨·말풍선 인식이 더 정확하고, 효과음·쪽 번호는 자동으로 빼 줌 |
| VisionKit 문서 스캐너 (자동 크롭·보정) | iPad 카메라 + ⟳ 회전 | 웹에서 사용 불가. Claude가 기울어진 사진도 읽음 |
| 페이지 드래그 정렬 | ◀ ▶ 버튼 정렬 | iPad 터치에서 더 안정적 |
| AVSpeechSynthesizer | Web Speech API | Safari 안에서 같은 iPad 음성 엔진을 사용 |

비용 감: 10쪽 책 1권 = OCR 10회 + 퀴즈 1회 (Sonnet 5.5 기준 대략 150~250원). 단어 뜻은 한 번 찾으면 저장됩니다.

## 5. 파일 구성
```
index.html, styles.css, manifest.webmanifest, sw.js(오프라인 캐시), icons/
js/main.js     라우팅, 부모 잠금
js/shelf.js    아이 책장
js/reader.js   읽기 화면 (재생, 하이라이트, 구간·반복·속도, 단어 뜻)
js/quiz.js     퀴즈 풀이, 채점, 해설, 결과
js/parent.js   책 편집(촬영·OCR·수정·퀴즈 관리), 학습 기록, 설정, 백업
js/speech.js   음성 재생 래퍼 (boundary 이벤트 + 시간 추정 하이라이트)
js/claude.js   Claude API (OCR, 퀴즈 생성·검증, 단어 뜻)
js/db.js       IndexedDB 저장소
js/text.js     문장·단어 분리
```
코드를 고친 뒤에는 `sw.js`의 `CACHE` 이름(v1 → v2)을 올리면 iPad에서 새 버전을 확실히 받습니다.

## 6. 알려진 제한
- 단어 하이라이트는 Safari의 음성 위치 이벤트를 쓰고, 이벤트가 오지 않으면 시간으로 추정합니다. 실제 iPad에서 어긋남이 크면 알려 주세요.
- 실제 Claude API·iPad 실기기로는 아직 테스트하지 않았습니다. (가짜 API·가짜 음성으로 전체 흐름 자동 테스트 17개 항목 통과)
- 데이터는 그 iPad의 그 주소(origin)에만 저장됩니다. 주소를 바꾸면 백업 → 불러오기로 옮기세요.
